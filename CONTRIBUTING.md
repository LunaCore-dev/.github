# Contributing to LunaCore

Thanks for helping. The rules for every LunaCore repository live in one place, so they never go
out of date: **https://lunacore.dev/guidelines/contributing.md**

The short version:

- Sign the Contributor License Agreement when the bot asks on your first pull request.
- Work on your own branch (`feature/…`, `fix/…`); `main` only changes through reviewed pull requests.
- Commit lines start with `[Added]`, `[Fixed]`, `[Changed]`, `[Removed]` or `[Other]`; fixes end with
  the issue reference, e.g. `(#42)`.
- If an AI helped, end the commit message with `Assisted By AI Model: <model name>`.
- Security problems go to https://lunacore.dev/support, never to a public issue.

Using an AI coding agent? Point it at the guidelines URL above from your `AGENTS.md` or `CLAUDE.md`.
