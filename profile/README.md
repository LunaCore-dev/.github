LunaCore builds **free tools for Minecraft server owners and developers**: mods you can run on
any server, documented APIs to build on, and a site where every release, report and answer is
public.

## Get help, report, follow along

| | |
|---|---|
| **Found a bug or have an idea?** | File it on [lunacore.dev/reports](https://lunacore.dev/reports) or in the product's `#issues` forum on Discord. Every report is public. |
| **Need an answer now?** | Ask [LunaAI](https://lunacore.dev/ai), which knows every product, or the community on [Discord](https://discord.lunacore.dev). |
| **Account or private matter?** | Open a ticket at [lunacore.dev/support](https://lunacore.dev/support). |
| **What changed?** | Every release and update is on the [changelog](https://lunacore.dev/changelog) and in each product's `#changelog` on Discord. |
